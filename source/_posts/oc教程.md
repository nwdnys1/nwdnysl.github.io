# 本地部署OpenClaw步骤指南

## 0. 环境准备

- OpenClaw需要nodejs环境 请确保已安装Node.js并配置好环境变量 可以去官网点击下载链接：https://nodejs.org/dist/v24.15.0/node-v24.15.0-x64.msi
- 安装后打开cmd 输入`node -v`和`npm -v`，如果都能正常显示版本号，则表示安装成功。

## 1. 安装OpenClaw

- 在cmd中输入以下命令并按回车键执行。
  ```bash
  npm i -g openclaw
  ```

## 2. 运行首次配置向导

- 在cmd中继续输入以下命令并按回车键。
  ```bash
  openclaw onboard
  ```
- 此命令将启动交互式配置程序。先选择YES（输入y），选择QUICKSTART，然后我们去获取可用的大模型api。

## 3. 获取AI模型API密钥

1. 使用浏览器访问“阿里云百炼”平台并登录账号。
2. 在平台左侧菜单栏中找到并点击“密钥管理”。
3. 点击“创建API Key”按钮。
4. 创建成功后，复制生成的密钥（Key）。
5. 回到步骤2中正在运行的`openclaw onboard`配置向导界面。模型配置中找到QWEN CLOUD，然后输入API Key，模型选择默认即可。

## 4. 创建并配置飞书机器人应用

1. 使用浏览器访问“飞书开放平台”(open.feishu.cn)并登录。
2. 点击“创建企业自建应用”，应用类型选择“机器人”，填写应用基本信息后点击创建。
3. 应用创建成功后，在左侧菜单进入“凭证与基础信息”页面。复制此页显示的“App ID”和“App Secret”。
4. 在左侧菜单进入“事件与回调”页面，进行以下配置：
   - 在“订阅方式”中，选择“长连接订阅方式”。
   - 在“添加事件”中，至少勾选添加“`im.message.receive_v1`”（接收消息）事件。
   - 点击“保存”按钮。

## 5. 在配置向导中绑定飞书机器人

- 操作：回到`openclaw onboard`配置向导界面。当向导提示输入飞书应用凭证时，在对应位置分别粘贴步骤4.3中复制的“App ID”和“App Secret”，并按照向导后续提示完成所有配置步骤。

## 6. 启动网关服务

- 操作：在终端中输入以下命令并按回车键执行。
  ```bash
  openclaw gateway
  ```
- 注意：
  - 命令执行后，终端将显示服务运行状态，并通常会输出一个本地管理后台的访问地址（如`http://localhost:18789`）。
  - 启动网关服务的终端窗口需保持打开，不要关闭。

## 7. 访问管理后台并验证

1. 打开浏览器，在地址栏中输入步骤6中命令提示的本地地址（例如`http://localhost:18789`）并访问。
2. 登录OpenClaw管理后台。
3. 在管理后台中检查事件订阅模式是否为“长连接”，并确认已添加的事件列表完整。

## 8. 测试机器人功能

- 操作：打开飞书App，找到你创建并已添加到聊天中的机器人。在对话框中`@`机器人并发送一条消息（例如“你好”）。观察是否收到机器人的回复。

## 排错指引

- 若`onboard`配置向导卡住或报错：检查网络连接，尝试重新执行`openclaw-cn onboard`命令。
- 若`gateway`启动失败：检查默认端口18789是否被占用。可尝试指定其他端口启动，命令为`openclaw-cn gateway --port 新端口号`。
- 若飞书机器人无回复：按顺序确认：1) 飞书后台事件订阅方式为“长连接”；2) 已添加`im.message.receive_v1`事件；3) 配置向导中填写的“App ID”、“App Secret”、“API Key”均准确无误。
- 若机器人回复空白或AI模型无响应：确认阿里云百炼的API Key有效且账户有足够配额。
